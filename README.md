# Ecommerce Order Management System (OMS)

A Spring Boot based Ecommerce Order Management System demonstrating modern backend development practices.

## Features

- User Authentication & Authorization (JWT)
- Product Management
- Inventory Management
- Product Reviews (MongoDB)
- Redis Caching
- Swagger/OpenAPI Documentation
- Liquibase Database Migrations
- MySQL Database
- Spring Security
- Exception Handling
- Validation

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- MongoDB
- Redis
- Liquibase
- Maven
- Swagger / OpenAPI

## Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-username>/ecommerceoms.git
```

### Navigate to project

```bash
cd ecommerceoms
```

### Configure

Update the database credentials in:

```
application.properties
```

### Run

```bash
mvn spring-boot:run
```

## API Documentation
